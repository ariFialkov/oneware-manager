# ASO

1. From the game sheet, list the player-language terms for the mechanic,
   theme and feeling (e.g. "block puzzle", "satisfying", "relaxing").
2. Research: look at the top ~10 App Store competitors for those terms
   (web search for their listings). Note the words in their titles and
   subtitles and how their first screenshot hooks. New studios can't win
   head terms, so aim for **long-tail terms** (2–3 words, specific) where
   the top results are weak or old.
3. Build fields (Apple indexes name + subtitle + keyword field together;
   don't repeat words across them):
   - Name ≤ 30: brand word + strongest keyword ("Stackly: Block Puzzle").
   - Subtitle ≤ 30: second keyword cluster + benefit.
   - Keywords ≤ 100 chars: comma-separated, no spaces, singular forms,
     no "game"/"app"/category names/competitor brands.
   Count characters exactly.
4. Screenshot brief: 5 frames, first two carry the decision. Big caption
   (≤ 5 words) + real gameplay. Hook → core loop → progression → variety →
   reward. Specify for 6.9" (1320×2868) — App Store scales down.
5. Icon brief: one object, bold silhouette, readable at 60 px, no text.
6. Test plan: use Product Page Optimization (up to 3 treatments) to test
   icon or first screenshot. One variable at a time, run until each arm
   has ~1,000+ impressions.
7. Write everything into the game sheet "Store listing" section.
